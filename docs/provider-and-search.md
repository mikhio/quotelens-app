# Модель и открытые источники

QuoteLens использует внешнюю модель для планирования исследования. Проверку доказательств, сопоставление и расчёт выполняет сервер. Подключение и переменные окружения описаны в [настройках](configuration.md), весь поток — в [архитектуре](architecture.md).

## Провайдер модели

Оператор задаёт `MODEL_API_BASE`, `MODEL_NAME` и серверный ключ. Провайдер должен поддерживать Chat Completions с вызовами инструментов. Резервный поиск Exa реализован через OpenRouter; его наличие у другого совместимого провайдера не предполагается.

Без ключа приложение запускается: доступны интерфейс, API и синтетические сценарии проверки. Живое исследование требует настроенного провайдера и доступа в интернет. Синтетический сценарий не подтверждает актуальную рыночную цену.

Ключ не вводится посетителем сайта. Он хранится вне репозитория и передаётся контейнеру как файл только для чтения. Исходное описание закупки и фрагменты открытых страниц могут отправляться внешней модели; для этой версии используйте только открытые неконфиденциальные данные.

## Обнаружение и чтение страниц

1. Агент ищет кандидатов в открытой выдаче DuckDuckGo; при недоступности выдачи у OpenRouter предусмотрен резервный поиск Exa.
2. Найденный URL открывается отдельно через HTTPS. Для страниц с JavaScript предусмотрен Chromium. Сниппет и текст ответа модели не считаются подтверждением цены.
3. Сервер сохраняет страницу, текст, URL, время и хеш; проверяет, относится ли цена к конкретному товару, и связывает поля с цитатами.
4. Недоступность сайта, robots, CAPTCHA, тайм-аут или отсутствие поля сохраняются как ограничения результата. Каталог помогает найти карточки и сам не становится предложением.

В интерфейсе можно ограничить исследование выбранными доменами. Название площадки в списке означает область поиска открытых страниц. Оно не означает подключённый официальный API, гарантированную доступность или полный охват площадки. Встроенных специализированных коннекторов к ЕИС и ГИСП в этой версии нет.

| Извлечение и проверка полей | [extraction.py](../quotelens/extraction.py) |

Адаптер регистрируется доверенным серверным кодом и реализует `discover` и `capture`. Его результаты проходят общий конвейер доказательств; сниппеты не заменяют первичный документ. Посетитель не может зарегистрировать исполняемый адаптер через API.

История поиска может дать ссылки для повторного исследования. Цены и характеристики по ним читаются заново; сохранённая старая цена не подменяет живой поиск. Выборка ограничена политикой исследования и бюджетом оператора и не представляет весь рынок.
