# Конфигурация и запуск

Основной запуск описан в [README](../README.md). `compose.yaml` читает `.env`; обычный запуск Python автоматически этот файл не загружает. Ключи, `.env`, `secrets/` и `.runtime/` не включаются в Git или архив исходников.

## Модель и ключ

| Переменная | Значение в примере / по умолчанию | Назначение |
| --- | --- | --- |
| `MODEL_API_BASE` | В `.env.example`: `https://openrouter.ai/api/v1`; без настройки пусто | Базовый адрес совместимого Chat Completions API с вызовом инструментов. Для внешнего провайдера нужен HTTPS. |
| `MODEL_NAME` | В примере: `openai/gpt-5.6-luna`; без настройки пусто | Идентификатор доступной оператору модели. Значение в примере не гарантирует доступность у провайдера. |
| `MODEL_KEY_FILE` | `./secrets/model.key` | Путь к файлу ключа **на хосте** для Compose. |
| `MODEL_API_KEY_FILE` | В контейнере: `/run/secrets/model_api_key` | Путь к файлу, который читает приложение. Без Docker задаётся самостоятельно. |
| `MODEL_API_KEY` | Пусто | Альтернативная передача ключа через окружение; имеет приоритет над файлом. Предпочтителен файл секрета. |
| `MODEL_JSON_MODE` | `1` | Запрашивать JSON-ответ при вспомогательных структурированных обращениях. При несовместимости провайдера можно отключить значением `0`. |
| `MODEL_ALLOW_NO_AUTH` | `0` | Разрешить модель без ключа для доверенного локального сервиса. |

Для живого поиска заполните файл ключа и обе переменные адреса/модели. Не вставляйте ключ в исходники, адреса, отчёты или команды, которые могут попасть в историю shell. Для замены файла с правами `444` сначала сделайте его доступным владельцу на запись, сохраните ключ и верните права `444`; каталог `secrets` остаётся с правами `700`.

После изменения настроек или ключа пересоздайте контейнер: `docker compose up -d --force-recreate`. Сам файл не включает автоматическую перезагрузку провайдера.

## Порты и хранение

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `QUOTELENS_BIND_IP` | `127.0.0.1` | Адрес публикации порта Compose. Для внешнего доступа оператор отдельно настраивает HTTPS и доступ к приложению. |
| `QUOTELENS_PORT` | `8765` | Порт на хосте; внутри контейнера приложение слушает `8000`. |
| `HOST`, `PORT` | Без Docker: `127.0.0.1`, `8765` | Адрес и порт процесса Python. В Dockerfile заданы `0.0.0.0` и `8000`. |
| `APP_DATA_DIR` | Без Docker: `.runtime` в корне; в контейнере: `/runtime` | Каталог SQLite и результатов. Compose подключает постоянный том `results`. |
| `APP_ALLOWED_ORIGIN` | Пусто | Дополнительный разрешённый Origin для операций записи. По умолчанию используется тот же хост. |
| `APP_PUBLIC_SHARE_BASE` | `/api/shared/` | Основа ссылки на сохранённую версию. Можно задать собственный публичный адрес или относительный префикс, например `./api/shared/`. |
| `BROWSER_EXECUTABLE_PATH` | Не задан | Путь к существующему Chrome/Chromium при запуске Python. Стандартный Compose использует браузер из образа и эту переменную не передаёт. |

`docker compose down` сохраняет том. Удаление тома удаляет исследования, доказательства, историю исправлений и квоты; для сохранения данных нужна резервная копия тома.

## Квоты и оценка расхода

После рекомендуемого `cp .env.example .env` действуют **12 запусков в сутки и 96 модельных обращений накопительно**. Без `.env` и без переопределения окружением Compose использует другие значения: дневной предел отключён, накопительный предел — 10 000 обращений. Это разные профили настройки.

| Переменная | `.env.example` | Compose без `.env` | Смысл |
| --- | ---: | ---: | --- |
| `APP_SEARCH_RUNS_DAY` | 12 | 0 | Дневной предел живых запусков/продолжений; `0` отключает именно этот предел. |
| `APP_MODEL_CALLS_TOTAL` | 96 | 10 000 | Накопительный предел модельных обращений. |
| `APP_MODEL_TOKENS_TOTAL` | 1 500 000 | 1 500 000 | Накопительный предел резервируемых токенов. |
| `APP_MODEL_MICRO_USD_TOTAL` | 2 000 000 | 2 000 000 | Предел внутреннего денежного резерва в micro-USD; 2 000 000 соответствует $2. |
| `MODEL_INPUT_MICRO_USD` | 1 | 1 | Верхняя оценка стоимости одного входного токена в micro-USD. |
| `MODEL_OUTPUT_MICRO_USD` | 5 | 5 | Верхняя оценка стоимости одного выходного токена в micro-USD. |
| `APP_ACTUAL_COST_SETTLEMENT` | Не задан | 0 | При `1` сверять денежный расход по полю `cost` провайдера; использовать после проверки его семантики. |

Перед модельным вызовом сервер резервирует токены и стоимость. Вход оценивается консервативно по размеру UTF-8, выход — по максимальному объёму; при успешном ответе с корректным `usage` неиспользованная часть возвращается. При ошибке или неизвестном расходе полный резерв сохраняется. Число обращений не уменьшается. Это внутренний ограничитель, а не гарантия размера счёта провайдера; оператор проверяет ставки выбранной модели.

Квоты хранятся в SQLite и переживают перезапуск. Дневные запуски считаются по дням UTC; накопительные модельные квоты не обнуляются при смене дня. Повышение значения в `.env` меняет предел, сохраняя уже учтённый расход.

Отдельный бюджет закупки задаётся `search_policy` в API или параметрами интерфейса: готовность позиций, время или число найденных цен. Подробности режимов и ограничений API — в [архитектуре](architecture.md).

## Внешние сервисы и источники

| Зависимость | Для чего нужна и что происходит при отсутствии |
| --- | --- |
| API модели | Планирование исследования и вызовы инструментов. Без настройки живой поиск не выполняется как полноценное исследование; интерфейс и сохранённые сценарии доступны. |
| DuckDuckGo Lite/HTML | Основной поиск адресов кандидатов. Сниппет сам по себе не является подтверждённой ценой. |
| OpenRouter Exa | Резервный поиск при недоступности основной выдачи; используется только с совместимым OpenRouter-провайдером. Отдельного ключа Exa приложение не запрашивает. |
| Публичные сайты поставщиков | Первоисточники цен и характеристик. Robots, CAPTCHA, ошибки и отсутствие цены отражаются в результате. |
| Playwright и Chromium | Чтение страниц с JavaScript и экспорт PDF. Устанавливаются Dockerfile; DOCX создаётся приложением. |
| `pypdf` | Извлечение текста из загруженного PDF; распознавания сканов нет. |

Для модуля `retrieval.py` предусмотрены `SEARCH_API_URL` — адрес поискового JSON endpoint, `SEARCH_API_KEY` — его Bearer-ключ и `SOURCE_ALLOWED_DOMAINS` — дополнительные разрешённые домены. Агентский цикл использует DuckDuckGo, резерв провайдера и `source_scope` запроса. Эти настройки не подключают официальный API ЕИС или другой площадки.

## Запуск без Docker

Нужны Python 3.12+, системные зависимости Chromium и доступ к установке пакетов:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python3 -m playwright install --with-deps chromium
```

Без модели:

```bash
python3 -m quotelens.server
```

Для живого поиска экспортируйте значения `MODEL_API_BASE` и `MODEL_NAME`, выбранные у провайдера, затем задайте путь к своему файлу ключа:

```bash
export MODEL_API_KEY_FILE="$PWD/secrets/model.key"
python3 -m quotelens.server
```

Приложение откроется на http://localhost:8765, данные будут в `.runtime/`. Остановка — `Ctrl+C`. Python-процесс автоматически `.env` не читает. Запуск без модели и тестовые снимки не подтверждают доступность живого поиска.

## Диагностика

`docker compose ps` показывает состояние контейнера, `docker compose logs --tail=100 quotelens` — журнал. `/health` проверяет HTTP-сервер; `/api/config` показывает настройку модели без секрета. Успешный healthcheck не доказывает доступность внешнего провайдера или сайтов.

Если Compose сообщает об отсутствующем файле секрета, создайте `secrets/model.key` или проверьте `MODEL_KEY_FILE`. Если поиск остановлен по квоте, проверьте сохранённый расход и нужный предел; перезапуск не обнулит его. Для проверки без платного внешнего обращения используйте сценарии и тесты из [scenarios.md](scenarios.md).
